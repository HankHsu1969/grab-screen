GrabScreen 螢幕擷取 {VERSION}　安裝說明
==========================================

1. 先把這個 ZIP 解壓縮：在 ZIP 檔上按右鍵 →「全部解壓縮」
   ※ 請不要直接在 ZIP 裡面點兩下執行

2. 點兩下 GrabScreen-Setup-{VERSION}.exe 開始安裝（不需要系統管理員權限）

3. 如果出現藍色的「Windows 已保護您的電腦」：
   按「其他資訊」→「仍要執行」
   （這個小工具沒有付費的程式碼簽章，屬於正常情況）


裝好之後
--------
・Ctrl + Alt + 1　全螢幕擷取
・Ctrl + Alt + 2　視窗 / 物件擷取（滑鼠移到哪就框哪，滾輪調整範圍）
・Ctrl + Alt + 3　自行框選擷取
・擷取後直接 Ctrl + V 就能貼到 LINE、Word、簡報
・右下角跳出的小視窗按「開啟編輯」，可以加框框、箭頭、文字、編號、馬賽克
・右鍵點右下角時鐘旁的星星圖示，可以改快捷鍵或其他設定

移除：Windows「設定 → 應用程式 → 已安裝的應用程式」→ GrabScreen 螢幕擷取 → 解除安裝

需要 Windows 10 或 11。
網站：https://github.com/HankHsu1969/grab-screen
