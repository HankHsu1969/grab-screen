## 商店清單（Store listing）

### 產品名稱
GrabScreen 螢幕擷取

### 描述（Description）

```
按一個快捷鍵，就能把螢幕畫面抓進剪貼簿，馬上貼到 LINE、Word、簡報或 Email。抓完還能開啟內建編輯器，用框框、箭頭、文字、編號和馬賽克把重點標清楚。

【三種擷取方式】
• Ctrl + Alt + 1　全螢幕擷取
• Ctrl + Alt + 2　視窗 / 物件擷取：滑鼠移到哪裡，就自動框出那個視窗、按鈕或面板；滾輪可以放大縮小範圍，移到標題列就選整個視窗
• Ctrl + Alt + 3　自行框選：附放大鏡，可以精準對齊到每個像素

擷取完成後，右下角會跳出小視窗，詢問要不要開啟編輯。

【內建編輯器】
• 方框、圓圈、箭頭、直線、畫筆、螢光筆
• 文字標示，自動加描邊，放在任何背景上都清楚
• 編號圓圈 ①②③，數字自動往上加，最適合做操作教學
• 馬賽克，快速遮住帳號、電話等個資
• 裁切、調整尺寸（已畫好的標示會跟著一起縮放）
• 復原 / 重做、縮放檢視；畫好的標示還能再移動、改大小、改顏色

【其他特色】
• 快捷鍵可以自訂，會即時檢查是否和其他程式衝突
• 支援多螢幕，以及 125%、150% 等螢幕縮放
• 完全離線：不需要網路、沒有廣告、不收集任何資料，截圖只會留在你的電腦
```

## 送審選項（Submission options）

### 受限功能說明（runFullTrust）
```
GrabScreen 是傳統 Windows 桌面程式（.NET Framework / Win32），需要 runFullTrust 才能提供核心功能：擷取整個螢幕畫面、註冊全域快捷鍵、常駐在系統匣，以及讀取視窗與介面元件的位置以便自動框選。程式完全離線，不會連網，也不收集任何資料。
```

### 給審核人員的說明（Notes for certification）
```
啟動後程式會常駐在工作列右下角的系統匣（藍色星星圖示），沒有主視窗。
測試方式：
1. 按 Ctrl + Alt + 3，拖曳框選一塊範圍，圖片會複製到剪貼簿，右下角跳出提示視窗。
2. 在提示視窗按「開啟編輯」，即可看到標示編輯器。
3. 按 Ctrl + Alt + 2 可體驗視窗 / 物件擷取；按 Ctrl + Alt + 1 為全螢幕擷取。
4. 右鍵點系統匣圖示，可以開啟「快捷鍵設定」、「其他設定」或結束程式。
不需要帳號，也不需要網路。
```
